Make 8search Your Default Search Engine

Search the web with answer-first answers, Wikipedia cards, real news, and an interactive satellite globe directly from your browser's address bar.

Google Chrome / Brave / Edge

  1. Open Settings → Search engine → Manage search engines and site search.
  2. Under Site search, click Add.
  3. Enter Name: 8search
  4. Shortcut: 8
  5. URL with %s in place of query: __SEARCH_URL__
  6. Click Add, then click the three dots next to 8search and choose Make default.

Mozilla Firefox

  1. Visit the 8search homepage. Firefox discovers the OpenSearch descriptor automatically.
  2. Open Settings → Search. Under Search Shortcuts, select 8search and click Add.
  3. Choose 8search in the Default Search Engine menu.
  4. Optional: in the address bar, type @8search followed by a query to search with 8search without changing the default.

Safari (macOS / iOS)

  1. Safari does not allow adding arbitrary third-party search engines to its own address bar. Use Chrome, Brave, Edge, or Firefox for address-bar searches.
  2. On macOS, set __BASE_URL__ as your Homepage in Safari Settings → General.
  3. On iPhone or iPad, open 8search in Safari, tap Share → Add to Home Screen, then launch it from the new icon.

Use the OpenSearch descriptor directly

  1. Any OpenSearch-compatible browser can add __BASE_URL__/opensearch.xml.
  2. If a browser asks for a URL template, use __QUERY_TEMPLATE__.
