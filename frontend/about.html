About

A search engine that learns from readers.

8search is an independent, answer-first search engine: quick answers, a Wikipedia card, videos, images, real news, and a live globe, all in one place.

What makes it different

Most search engines rank results with a secret mix of signals. 8search also listens to the simplest signal there is: when someone searches for a topic and clicks a result, that result was probably useful. When enough people click the same result for the same query, it moves up. Results nobody clicks move down.

Clicks lower on the page count for more, because the top few results get clicked by accident. Clicks fade with a 30-day half-life, and a single click cannot outrank a result with a strong history. Brand-new queries keep the upstream provider order until there is real click data.

How it is built

8search is a small project built with FastAPI, vanilla JavaScript, Leaflet, and public data sources. The interface stays light and quiet so the answer is the loudest thing on the page. News comes directly from publisher RSS feeds, and every headline links back to the publisher.
